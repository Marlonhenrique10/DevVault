# ADR-001

## Escolha do framework

Foi escolhido NestJS porque:

- Ele fornece uma arquitetura opinativa baseada em módulos.

- Injeção de dependência e decorators.

- Facilita a organização de projeto de médio e grande porte.

- Possui excelente integração com o TypeScript, possui suporte nativo a teste, validação, autenticação e microsserviços.
